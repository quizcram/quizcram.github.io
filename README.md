# QuizCram Open Reference Data

Open-source (MIT) reference tables and JSON datasets for US licensing and certification exams, maintained by [QuizCram](https://quizcram.com/).

## Included Datasets

- `data/clsi-order-of-draw.json` — CLSI PRE02 phlebotomy order of draw, tube colors, additives, and inversion counts.
- `data/fda-food-code-temps.json` — 2022 FDA Food Code minimum internal cooking, holding, and two-stage cooling temperatures.
- `data/comptia-a-plus-ports.json` — Common CompTIA A+ Core 1 (220-1201) network ports and protocols.

## Live Reference Portal

View the formatted tables and interactive links at **https://quizcram.github.io/**.
